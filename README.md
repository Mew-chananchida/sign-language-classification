# Sign Language Classification

โปรเจกต์สำหรับการจำแนกตัวอักษรภาษามือภาษาอังกฤษ **A–I** โดยใช้เทคนิค **Machine Learning และ Deep Learning** ผ่านโมเดล **Convolutional Neural Network (CNN)**

ระบบสามารถเก็บข้อมูลภาพภาษามือจากกล้อง นำข้อมูลมาใช้ในการฝึกโมเดล และนำโมเดลที่ผ่านการฝึกมาใช้สำหรับตรวจจับและทำนายตัวอักษรภาษามือแบบเรียลไทม์


## วัตถุประสงค์ของโครงงาน

### 1. เพื่อช่วยให้ผู้คนทั่วไปเข้าใจและเรียนรู้ภาษามือได้ง่ายขึ้น

พัฒนาระบบที่สามารถตรวจจับและแปลสัญลักษณ์ภาษามือ เพื่อช่วยให้ผู้สนใจสามารถเรียนรู้ภาษามือได้ง่ายขึ้น โดยนำเทคโนโลยีมาใช้เพื่อสร้างประสบการณ์การเรียนรู้ที่เข้าถึงได้มากขึ้น

### 2. เพื่อเรียนรู้การสร้างฐานข้อมูลสำหรับใช้ฝึกโมเดล

ฝึกฝนการจัดเตรียมข้อมูลภาพตัวอักษรภาษามือ และสร้างโครงสร้างฐานข้อมูลอย่างเป็นระบบ เพื่อให้สามารถนำข้อมูลไปใช้ในการฝึกโมเดล Machine Learning ได้อย่างเหมาะสม

### 3. เพื่อเข้าใจการประยุกต์ใช้ Machine Learning และการประมวลผลภาพ

เรียนรู้การนำเทคนิค Machine Learning และ Deep Learning มาใช้ร่วมกับข้อมูลภาพ รวมถึงการประมวลผลภาพ การตรวจจับมือ และการออกแบบโมเดลสำหรับจำแนกตัวอักษรภาษามือ

### 4. เพื่อพัฒนาทักษะการแก้ปัญหาและปรับปรุงโค้ด

ฝึกการคิดวิเคราะห์ การทดลอง และการปรับปรุงกระบวนการทำงานของโค้ด เพื่อเพิ่มประสิทธิภาพและความแม่นยำในการตรวจจับตัวอักษรภาษามือ รวมถึงการทดสอบและแก้ไขปัญหาอย่างเป็นระบบ

# ขั้นตอนการดำเนินงาน

โครงงานแบ่งการทำงานออกเป็น 3 ขั้นตอนหลัก ได้แก่

1. การสร้างฐานข้อมูล (Dataset)
2. การฝึกโมเดล (Model Training)
3. การนำโมเดลไปใช้งานกับกล้องแบบเรียลไทม์ (Real-time Prediction)

---

## 1. การสร้างฐานข้อมูล (Dataset)

เริ่มต้นจากการเก็บข้อมูลรูปภาพมือที่แสดงสัญลักษณ์ต่าง ๆ ของตัวอักษรภาษามือภาษาอังกฤษ ตั้งแต่ **A ถึง I**

ข้อมูลภาพถูกเก็บจากกล้องเพื่อสร้างชุดข้อมูลสำหรับใช้ในการฝึกโมเดล โดยมีการจัดเก็บข้อมูลตามแต่ละตัวอักษร

### กระบวนการทำงาน

โปรแกรมจะสร้างโครงสร้างโฟลเดอร์สำหรับเก็บข้อมูลภาพที่ได้จากกล้อง โดยสามารถบันทึกภาพในบริเวณที่กำหนด หรือ **ROI (Region of Interest)**

ระบบสามารถ:

- เปิดกล้องเพื่อเก็บข้อมูลภาพ
- กำหนดบริเวณ ROI สำหรับตรวจจับมือ
- บันทึกภาพมือสำหรับตัวอักษร A–I
- บันทึกภาพพร้อมข้อมูล Mask สำหรับการตรวจจับบริเวณมือ
- เริ่มหรือหยุดการเก็บข้อมูลตามปุ่มที่กำหนด
- เปลี่ยนตัวอักษรที่ต้องการเก็บข้อมูลได้

หลังจากเก็บข้อมูลแล้ว ภาพจะถูกนำมาเตรียมสำหรับการฝึกโมเดล โดยโหลดข้อมูลจากโฟลเดอร์และปรับขนาดภาพให้เหมาะสมก่อนนำไปใช้งาน

---

## 2. การฝึกโมเดล

ข้อมูลภาพที่สร้างขึ้นจะถูกนำมาใช้ในการฝึกโมเดล Deep Learning โดยใช้เทคนิค

**CNN (Convolutional Neural Network)**

เพื่อจำแนกรูปภาพภาษามือเป็นตัวอักษรภาษาอังกฤษตั้งแต่ **A–I**

### ขั้นตอนการฝึกโมเดล

1. โหลดข้อมูลภาพจาก Dataset
2. ปรับขนาดภาพเป็น **64 × 64 pixels**
3. แบ่งข้อมูลออกเป็นชุดฝึกและชุดทดสอบในอัตราส่วน **80:20**
4. สร้างโมเดล CNN
5. ฝึกโมเดลด้วยข้อมูลภาพ
6. ประเมินผลการทำงานของโมเดล
7. บันทึกโมเดลที่ผ่านการฝึกแล้วในรูปแบบ .h5

### โครงสร้างของโมเดล

โมเดล CNN ประกอบด้วยเลเยอร์หลัก ได้แก่

- Convolution Layer
- MaxPooling Layer
- Dense Layer

โดยกำหนดการฝึกโมเดลเป็น

- Image Size: 64 × 64
- Train/Test Split: 80:20
- Epochs: 10
- Batch Size: 32
